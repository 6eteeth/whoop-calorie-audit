# ZCore Learn Your Metabolism Update

This release repositions ZCore around its core purpose: helping people understand how Calories In vs. Calories Out affects their own body.

## Changes

- New homepage hero: **Learn Your Metabolism**
- Clear Calories In vs. Calories Out messaging
- New Nutrition, Body, Activity, Expenditure, Wearable Comparison, and Daily Context sections
- New answer-focused section built around the questions users want ZCore to solve
- New public wearable roadmap showing WHOOP as available and Garmin, Apple Health, Fitbit, and Oura as upcoming
- Expanded Integrations screen with provider cards
- Updated page title and search description

## Installation

Copy all files into the existing ZCore project, replace matching files, commit, and push to GitHub. No Supabase migration or new Netlify environment variables are required.
