# ZCore Story, Learning Center, Consistency, and Weekly Weight Update

This build adds public About, Consistency, and Learning Center pages, uses the two supplied photos, and adds a Sunday-to-Saturday weekly average weight chart to the dashboard.

## New URLs
- `/about`
- `/consistency`
- `/learning`

## Deployment
Copy this update over the existing GitHub project, commit, push, and wait for Netlify to publish. No Supabase migration or new environment variables are required.

## Suggested commit message
`Add About, Learning Center, consistency guide, and weekly weight averages`
